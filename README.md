# 🍽️ LunchBuddy

אפליקציה משפחתית לבחירת אוכל לילדים — כל ילד/ה בוחר/ת מה לאכול, וההורים עוקבים אחרי הבחירות, מציעים ארוחות ומנהלים רשימת קניות.

חי ב-**https://lunchbuddy-5fbda.web.app**, ודף שיווקי ב-`/welcome`.

## הרצה

```bash
npm install
npm run dev
```

## מה יש כרגע

**משפחות וסנכרון**
- כל משפחה מקבלת קוד בן 6 ספרות ומסמך Firestore נפרד משלה (`firebase.js`, `AppContext.jsx`) — כל מכשיר שיודע את הקוד רואה ומעדכן את אותם הנתונים בזמן אמת. בלי Firebase מוגדר (`.env` ריק) האפליקציה עובדת מקומית בלבד עם localStorage.
- כללי גישה ב-`firestore.rules`: אין רשימה/חיפוש של כל המשפחות, רק גישה למשפחה ספציפית עם הקוד שלה.

**כניסה לפי תפקיד**
- מסך פתיחה: "אני ילד/ה" או "אני הורה". ילד/ה שיוצר/ת פרופיל במכשיר שלו/שלה מחובר/ת מיד — קוד המשפחה עצמו הוא כבר האישור, אין קוד זיווג נפרד לכל ילד/ה.

**בחירת אוכל**
- קטגוריות, חיפוש, "תבחר לי" (בחירה אקראית), מועדפים ❤️, דירוג ⭐, "לא רוצה לבחור היום", היסטוריית בחירות
- רצף בחירות יומי 🔥 ואתגר שבועי 🌟

**הצבעה משפחתית 🗳️**
- ההורה בוחר/ת 2–4 מנות מועמדות, כל ילד/ה מצביע/ה, ההורה סוגר/ת את ההצבעה והתוצאה מוחלת אוטומטית על כל המשפחה

**אזור הורים**
- לוח משפחתי, תזכורות למי שעוד לא בחר, הצעת ארוחה לילד/ה ספציפי/ת, סטטיסטיקות עם גרף, רשימת קניות

**עיצוב וחוויה**
- ערכת נושא כהה/בהירה, מסך פתיחה אנימטיבי, מעברים חלקים בין טאבים, התראות (toast) על פעולות, אייקונים אחידים (lucide), תמיכה כ-PWA (ניתן להתקין למסך הבית)

בלי Firebase מוגדר, הנתונים נשמרים מקומית בדפדפן (localStorage) בלבד.
