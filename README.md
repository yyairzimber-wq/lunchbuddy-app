# 🍽️ LunchBuddy

אפליקציה משפחתית לבחירת אוכל לילדים — כל ילד/ה בוחר/ת מה לאכול, וההורים עוקבים אחרי הבחירות, מציעים ארוחות ומנהלים רשימת קניות.

## הרצה

```bash
npm install
npm run dev
```

### חיבור ל-Firebase (אופציונלי, לסנכרון בין מכשירים)

בלי הגדרה נוספת האפליקציה עובדת מקומית בדפדפן (localStorage). כדי שהורה וילד/ה על מכשירים נפרדים יראו את אותם נתונים בזמן אמת:

1. צרו פרויקט ב-[console.firebase.google.com](https://console.firebase.google.com) והוסיפו אפליקציית Web
2. הפעילו **Firestore Database** (Build → Firestore Database → Create database)
3. העתיקו את `.env.example` לקובץ בשם `.env` ומלאו בו את פרטי ה-`firebaseConfig`
4. הפעילו מחדש את השרת (`npm run dev`) — תג "☁️ מסונכרן" באזור ההורים יאשר שהחיבור פעיל

## מה יש כרגע

**כניסה לפי תפקיד**
- מסך פתיחה: "אני ילד/ה" או "אני הורה"
- ילד/ה יוצר/ת פרופיל ומקבל/ת קוד בן 6 ספרות; הורה מחבר/ת אותו/ה דרך טאב "ילדים" — עובד בזמן אמת בין מכשירים נפרדים כשמוגדר Firebase (ראו למעלה)

**בחירת אוכל**
- קטגוריות, חיפוש, "תבחר לי" (בחירה אקראית), מועדפים ❤️, דירוג ⭐, "לא רוצה לבחור היום", היסטוריית בחירות
- הוספת מאכלים מותאמים אישית ומחיקתם, מתכונים עם רשימת מצרכים לכל מאכל מובנה
- רצף בחירות יומי 🔥 ואתגר שבועי 🌟

**תכנון שבועי 📅**
- כל ילד/ה מתכנן/ת מראש מה לאכול בכל יום בשבוע

**"מה יש בבית?" 🧺**
- ההורה מסמן/ת מצרכים זמינים, והאפליקציה מציעה אילו מנות אפשר להכין מהם — גם אצל ההורה וגם אצל הילד/ה

**הצבעה משפחתית 🗳️**
- ההורה בוחר/ת 2–4 מנות מועמדות, כל ילד/ה מצביע/ה, ההורה סוגר/ת את ההצבעה והתוצאה מוחלת אוטומטית על כל המשפחה

**אזור הורים**
- לוח משפחתי, תזכורות למי שעוד לא בחר, הצעת ארוחה לילד/ה ספציפי/ת, סטטיסטיקות עם גרף, רשימת קניות

**פרופיל אישי**
- כל ילד/ה יכול/ה להעלות תמונת פרופיל מהגלריה במקום אווטאר חיה

**עיצוב וחוויה**
- ערכת נושא כהה/בהירה, מסך פתיחה אנימטיבי, מעברים חלקים בין טאבים, התראות (toast) על פעולות, אייקונים אחידים (lucide), תמיכה כ-PWA (ניתן להתקין למסך הבית)

## בהמשך

מערכת מתכונים מורחבת למאכלים מותאמים אישית, הצעות מבוססות AI.
